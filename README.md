# Coil

Coil is a fast neon grid-serpent game. Eat pulses to grow, plan safe turns, and chain pickups before the combo window expires to reach a ×5 multiplier.

## Run

```sh
npm ci
npm run dev
```

Build the self-contained static site with `npm run build`; the result is in `dist/`.

## Controls

- Arrow keys or WASD: steer
- Enter or Space: select
- P or Escape: pause
- M: mute
- Pointer or touch: menus
